# sijang.github.io

Personal academic homepage of Se-In Jang — https://sijang.github.io

A plain static site (no build step; `.nojekyll` tells GitHub Pages to serve files as-is).

- `index.html` — home (bio, experience, selected publications)
- `publications/`, `interests/`, `quotes/` — subpages
- `style.css` — shared styles (light/dark)
- `assets/img/SI1.jpg` — profile photo

To edit, change the HTML directly and push to the `source` branch.
